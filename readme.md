FirstRepo
¡Bienvenido a FirstRepo! Este es mi primer repositorio en GitHub, creado como parte de mi aprendizaje en el uso de Git y GitHub. Aquí experimentaré con conceptos básicos como commits, ramas, y manejo de archivos.

📁 Contenido
hola_mundo3.py: Un sencillo script en Python que imprime "Hola, mundo" en la consola. Ideal para probar configuraciones de entorno y flujos de trabajo de Git.

🚀 Objetivos del Proyecto
Familiarizarme con el flujo de trabajo de Git: clone, add, commit, push, pull.

Explorar la creación y fusión de ramas (branches).

Aprender a colaborar en proyectos utilizando GitHub.

Entender cómo documentar proyectos con archivos README.md.

🛠️ Tecnologías Utilizadas
Lenguaje: Python 3

Herramientas: Git, GitHub
